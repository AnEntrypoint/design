# Component -> source-sheet map

Generated by `node scripts/generate-component-sheet-map.mjs`. Do not hand-edit.

This answers the question that blocks a per-consumer CSS subset: for a given
component, which source sheets carry its rules? The build can only subset by
source sheet, and the sheets are named for app areas rather than components, so
without this map no consumer can declare what it needs.

## How to read it

A class defined in 4 or more sheets is treated as SHARED BASE -- a state or
utility token (active, group, btn, icon) that any subset has to carry regardless of
which components it includes. "Owned" sheets are those carrying a component's
distinctive classes. This split matters: counted naively, one shared token drags a
whole sheet in and every component looks scattered across 20+ sheets.

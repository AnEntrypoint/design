## No Chrome/Puppeteer/Playwright Dependency (CRITICAL)

Never add `puppeteer`/`puppeteer-core`/`playwright`/`playwright-core`, and never hand-roll a headless-Chrome launch. The ban is on the DEPENDENCY, not live-browser verification: `scripts/cdp.mjs` is a zero-dependency CDP client (Node global `WebSocket`) that only connects to a Chrome the caller started (`CDP_BASE`).

- It disables the network cache before first navigation (disk cache serves pre-edit CSS) and sets colour scheme + reduced-motion in one `Emulation.setEmulatedMedia` call (each call replaces the feature list).
- `scripts/a11y-audit.mjs` (`npm run a11y`, local gate) runs vendored axe-core against every `ui_kits/*/index.html`, ratcheted per kit in `scripts/a11y.baseline.json` (fails over AND under; a new kit starts at 0). Audit URLs keep a trailing slash (http-server 301s `/index.html`, giving a false-clean 0). WCAG-tagged rules only: `page-has-heading-one`/`bypass` are NOT covered, so check `h1` and skip link directly.
- `visual-baseline.mjs`: 1280x900 fixed (changing it invalidates every baseline).
- After any restyle that swaps base values re-run `npm run a11y`: hand-tuned contrast derivations break (it caught `--accent-fg` at 1.15:1 dark-on-dark).
- `lint-dead-controls` is the static counterpart: an EMPTY handler body or bare `href="#"` fails; the only escape is a `data-specimen` attribute on the line. Baseline 0, fails below too.
- `lint-yaml-parse` (hard zero): flatspace only logs YAML read errors, so a bad page yaml ships green; the gate fails on a plain scalar containing `: ` (quote it).

## Comment Policy

No comments anywhere (CSS, JS, HTML). Express intent in names; non-expressible rationale goes in this file. The one exception: JSDoc `@param`/`@returns` that the doc/type generators read (e.g. the `createDamageNumbers` factory; removing it types the return `VNode`). `colors_and_type.css` has zero comments; `generate-tokens-json.mjs` names `:root` groups from `ROOT_GROUP_BY_ORDINAL = ['root','colors-type']`, no banner parsing.

Swallowed errors: never an empty `catch` or `.catch(()=>{})`; use `attempt`/`attemptAsync`/`ignoreFailure` from `src/best-effort.js`. In freddie pages never `.catch(()=>null)` a fetch inside a page's `try` (hides the failure from `s.error`). A found comment triggers a full comment sweep (owner invariant).

## Design System Caveats

- **Visual north-star: shadcn-neutral**, system-font-only. Neutral grayscale: light `--accent` `#262626`, `--accent-ink` `#171717`; dark/ink `--accent` `#BFBFBF`, `--accent-ink` `--paper`. The former "Acid Editorial" lime lead, `--acid*` tokens, `--grain-opacity` and `.ds-grain`/`.ds-halftone` are gone. Hero is a centered flex stack. Motion: `--ease-drawer`/`--ease-collapse`/`--ease-out-strong` plus retained `--ease-spring`.
- **Accent split (contrast):** `--accent` is the FILL (behind `--accent-fg`); `--accent-ink` is the readable TEXT tone. Any `color:` accent MUST use `--accent-ink`; only `background`/`border-color` use bare `--accent`.
- **Typography:** `--ff-display`/`--ff-narrow`/`--ff-body` = `system-ui, sans-serif`; `--ff-mono` = `ui-monospace, Menlo, Consolas, monospace`; no `@import`/`@font-face`; `colors_and_type.css` is the single source. `--fs-*` is rem (WCAG 1.4.4). `--fs-pico` (10px) and `--fs-nano` (11px) are the floor, for glanceable secondary non-prose only; add no more sub-12px rungs.
- **Stacking is a token scale:** 13-rung `--z-*` ladder in `colors_and_type.css` (`below` -1, `base` 0, then `raised/sticky/header/drawer/window/dock/dropdown/modal/toast/tooltip/top` at 100 steps). No raw `z-index`; pick the rung by meaning or add one. Drawer: scrim `--z-drawer`, panel +1, toggle +2.
- **`transition: all` is banned**; name properties (all animates padding/border-width and resizes controls under the pointer).
- **`.ds-app-surface`** on the root of any application kit (dashboard, inspector, terminal, file browser, settings, search) opts into the app typescale (its heading rules are DESCENDANT selectors on purpose). `.ds-panel-trio/-duo/-flush` use real grid tracks stepping down on CONTAINER width; never express equal N-up with percentage flex-basis/spans.
- **Panel rhythm outer 2:1 inner:** outer `--space-5`, inner sibling gap `--space-3`, density-scaled. `[data-density]` must reach control internals, not only `--pad-x`. `--density` scales `--space-*`; `--ctl-*` and `--row-height` are per-tier whole-pixel tables, never a multiplier.
- **Themes:** a theme must bind all three `--bg-*` tiers and `--danger-ink` (else tier-3 text ~1.2:1). The `[data-theme]` surface-family block re-derives `--panel-*` and scrims per themed element (derived custom properties freeze where declared); new derived surface tokens go there. `--warn-fg` is text on a `--warn` FILL; `--warn`/`--danger` root values are paper-tuned and dark blocks restore ink-tuned ones. `herd`: brand orange is fill only, `--accent-fg` black, `--accent-ink` darkened orange. Dark palette is declared twice (`[data-theme="ink"]`, `prefers-color-scheme: dark`; `lint-dark-parity`). `src/theme.js` accepts `dark` as alias of `ink` and sets `data-theme` on `<html>`. `dynamic-accent.js` uses fixed role tones as a scoped subtree override with its own colour maths.
- **Reduced motion:** every animation sits inside a `prefers-reduced-motion` block. The neutralizer zeroes durations, not delays: a drawer transitioning `visibility` must zero its delay; same-node tab entrances need a distinct `animation-name` per tab. Scrollbar styling is one root rule.
- **`@media` cannot read custom properties.** Canonical breakpoints: 480, 768, 768-1024, 900/901, 1025; align near-misses when touching a rule.
- Older policy (zero-border aesthetic, pill radius scale, list-row primitives, ...): rs-learn "list bg borders", "pill radius scale", "box-shadow stripped", "list primitives", "fab cta sidebar".

## CSS Lint Gates

`npm run lint` runs 17 gates (`CHECKS` in `scripts/lint-css.mjs`; token gates in `lint-tokens.mjs`, shared ratchet code in `lint-shared.mjs`) over 41 component sheets. Hard zero: `tokens` (no raw colour), `radius` (`--r-*`), `zindex`, `transition-all`, `dark-parity`. Ratchets with frozen `scripts/lint-*.baseline.json`: `spacing` (119), `fontsize` (32), `important` (36), `inline-css` (6), `inline-styles` (10) (the files are the truth). The rest: `tokens-json`, `glyphs`, `null-children`, `classes`, `duplicate-selectors`, `empty-catch`, `dead-controls`.

- **A barrel lints nothing on its own.** Root `app-shell.css` is an `@import` barrel over `src/css/app-shell/*.css`. `COMPONENT_SHEETS` lists ENTRY POINTS; `expandSheets()` resolves the `@import` graph and every scanner iterates the expansion.
- **Barrel completeness is a hard gate:** `FULL_COVERAGE_DIRS` (`src/css/app-shell`) requires every `.css` there in the scan set: `@import` it in the root barrel (or list it in `COMPONENT_SHEETS`). `build.mjs` keeps its own `appShellSplitFiles` list, so a sheet can ship in `dist/247420.css` while a consumer `<link>`ing `app-shell.css` renders it unstyled; `CSS_PARTS` in `lint-duplicate-selectors` mirrors both.
- **A ratchet baseline is a debt figure to drive DOWN, never a budget.** Re-freeze downward (`--write-<flag>-baseline`) when the count drops; never raise one for a new violation; below-baseline also fails. The only legitimate rise is scan-set widening. Gates once read green over unscanned ground (barrel, sheets missing from `COMPONENT_SHEETS`, HTML `<style>`, recursive `src/components`, preview trees): when adding a gate, check its scan set against what ships.
- **Consumer sheets are a SECOND corpus.** `DS_LINT_EXTRA_CSS_FILES`/`DS_LINT_EXTRA_JS_DIRS` point these scripts at a consumer's CSS; `ratchetOrThrow` counts them against `DS_LINT_EXTRA_{SPACING,FONTSIZE,IMPORTANT,INLINE_CSS}_BASELINE` (default 0), never the kit baseline. A genuinely load-bearing consumer violation pins that env var in the CONSUMER repo with a stated reason; never ask for the kit baseline to rise.
- **Off-scale literals are NAMED, never snapped blind and never commented.** Declare the literal as a custom property on the rule that uses it (`--bubble-inset-x: 14px; padding: var(--space-2-5) var(--bubble-inset-x)`); the scanner regexes use `(?<![\w-])`, so a literal on a custom-property declaration is accepted. The `margin: -1px` visually-hidden idiom stays literal (`lint-duplicate-selectors` diffs it against `.sr-only`).
- **Structural exemptions:** `var(--tok, literal)` fallbacks, shadow tints, and `calc()` (font-size also `max/min/clamp`) anchored to a `--r-/--space-/--fs-/--z-` token are derived values. `max(16px, var(--fs-body))` passes by design (16px = iOS auto-zoom threshold); `max()`/`clamp()` with NO token fails. `%` is excluded from SPACING_RE and `border-radius: 0` never flagged; `em` font-size/spacing ARE counted.
- **`ALLOW`/`RADIUS_ALLOW`** (`lint-tokens.mjs`) are tiny audited per-file substring exemptions, separate lists so one rule's exemption cannot exempt another. Entries for `border-radius: 11px` (plugins-config.css), `999px` (app-surfaces.css), `4px`/`6px` (spoint game-hud.css) are DEBT: delete when moved to `--r-*`. The print palette restated in `@media print` (app-surfaces.css) is real token definition and stays.
- `lint-inline-css` masks HTML comments and `style="..."` attributes before extracting `<style>`; a ratchet, not an allowlist. `lint-inline-styles` skips `src/components/game-editor-kit/` (CDN-served, carries layout inline) and `dist/`.
- `lint-glyphs` scans `src`, `ui_kits`, `slides`, `site`, `preview` and the shipped root sheets; exempts `preview/icons-unicode.html`. `lint-classes` scans `src/components` recursively; its frozen bare-name list is closed; `dim` is debt (end state `.ds-dim`, rule in `base.css` and call sites move together).
- `lint-duplicate-selectors` flags a same-selector pair only at >=3 shared properties, >=70% overlap and a conflicting value.
- `lint-tokens-json` runs inside `npm run lint` and compares whitespace-insensitively (multi-line `--shadow-*` values; CRLF vs LF).
- **Every gate must be proven to FAIL:** inject a violation (confirm FAIL + exit 1), then a negative control (`var(--token, fallback)`) must not false-positive.

## CSS Authoring Rules

- **A rule only exists where its consumer links it.** Most kits link only `colors_and_type.css` + `app-shell.css`; a rule in a separately published sheet (`community.css`, `gm-prose.css`, `chat.css`, `editor-primitives.css`) is undefined for a kit not linking it. Shared utilities (`.sr-only`, prose) belong in `app-shell.css`. Kit `<link>` sets change via `ui_kits/kits.config.mjs` + `scripts/generate-ui-kit-scaffolds.mjs`, never by hand-editing generated `index.html`. ChatComposer/chat-message-parts need `chat.css`; Dialog/EmojiPicker/CommandPalette chrome is only in `editor-primitives.css`; file_browser needs `chat.css` for `.ds-file-more/-count/-btn` and `.ds-preview-*`.
- **Before shipping a page, check every class it uses against the sheets it links.** A class with no rule silently renders browser defaults: the most recurring defect shape here. `scripts/generate-component-sheet-map.mjs` maps component -> sheets (resolves nested barrels transitively; a class defined in 4+ sheets, `SHARED_AT`, is shared base).
- **No inline `style="..."` in components;** add a `.ds-<thing>` class to `app-shell.css` (the build prefixes `.ds-247420`).
- App-shell sheets: (1) the single reduced-motion net is in `base.css`, its `!important`s required (`.ds-247420 *` is (0,1,0)); standalone sheets keep their own. (2) `margin: auto` on a flex/grid item disables stretch: `.ds-prose`, `.app-main.narrow`, `.panel-inline-wide` need `width: 100%`. (3) Flex/grid sibling margins never collapse: a gap is owned by ONE side. (4) Beat a sibling with `.app`-scoped specificity, not `!important`. (5) Order is behaviour: drawer-toggle `display:none` bases and the FillLines screen rule sit BEFORE the media/print blocks overriding them. (6) `.row-form input` background/box-shadow `!important` is required (`states-interactions.css` loads later). (7) `.cli` and the terminal kit are always-ink: tone text from `--paper-*`/`--brand-green`, not `--fg-*`. (8) Sticky chrome carries opaque `var(--bg)`; `.app-doc-scroll` opts out of the 100dvh clamp; `.canvas-host` makes shells transparent. (9) `.panel-wide` is its own container-query context. (10) Text picks: `--green` (not `--success`), `--warn-fg` on `--warn` fill, `--mascot-deep`, `--accent-ink`; `--on-color` fails AA on `--mascot` (use `--ink`). (11) Print forces `--ink`/`--paper`, real borders, hides interactive chrome.
- `community-app.css` scopes every rule under `.ca-app` (dist re-scope `.ds-247420.ds-247420` out-specifies the merged-chrome reset). `.chat-stack` alone owns the chat measure (`.chat-msg-flat` sets no `max-width`).
- Verify against the real AX tree and rendered geometry, not computed style: `.sr-only` must be PRESENT in the AX tree and clipped 1x1; touch targets are measured under coarse-pointer emulation. The `.skip-link` 44px floor is unconditional (not behind `pointer:coarse`).
- Scroll containers (JsonViewer, Table wrapper) are always `tabindex=0` + `role=group` + aria-label, never `role=region` (`scrollable-region-focusable`; Table fires only on real overflow, so repro at 1024x768).
- `build.mjs` CSS scoping: `body`/`html body` map to `:is(.ds-247420, .ds-247420 body)` before the bare `html` branch; `:root` becomes the scope. It temporarily overwrites `src/styles.js` with the gzip+base64 decoder and restores it in `finally`.
- `generate-tokens-css.mjs` splices values in place (tokens.json holds only `:root`; the `[data-theme]/[data-density]/[data-accent]/[data-typescale]` blocks are hand-authored). `site.yaml` `accent_from/accent_to` mirror `--green/--green-2`.

- **Consumers** (no bundler) load unpkg `dist/247420.css` + module `dist/247420.js` to populate `window.ds`; render with `ds.applyDiff(rootEl, ds.components.AppShell({topbar, crumb, side, main, status}))`. The root MUST carry `class="ds-247420"` (not `app247420`) BEFORE `applyDiff`: every rule in `dist/247420.css` is prefixed with it (`src/styles.js`: `scope = '.ds-247420'`).
- **Router:** use `new ds.Router({ fallback })` (`src/router.js`). rs-learn "SDK hash router Router register navigate".
- **Bootstrap:** every ui_kit goes through `mountKit({ root, view, screen })` from `src/bootstrap.js`; no new motion/CDN/applyDiff loops in kit `app.js`. Kits import from owning submodules (`ds/components/shell.js`), never the `ds/components.js` barrel (native ESM fetches its whole ~196-module graph). Thin kit shells are generated from `ui_kits/kits.config.mjs` + `_template/index.html.tmpl` (keep `.tmpl`: as `.html` it served a broken page of `{{VAR}}`); blog, docs, community-app, workspace, os, component_explorer are hand-authored and stay out of the config. - **Component layout:** `src/components.js` is a barrel, do not extend it; add `src/components/<group>.js` and re-export. 200-line cap per module. A group that outgrows it becomes a thin barrel over single-responsibility submodules in a same-named sibling directory; the public export surface must not move. **Group barrels MUST use import-then-bare-export** (`import { X } from './sub.js'` ... `export { X }`), never pure `export { X } from`, which makes `generate-component-docs.mjs` emit drift warnings. Re-run `npm run docs:components` after any split.
- **One extraction, two artifacts:** `scripts/component-surface.mjs` is the ONLY parser of the component surface; `generate-component-docs.mjs` (`docs/component-props.md`) and `generate-component-types.mjs` (`types/*.d.ts`) render its model. The doc generator matches the FIRST `const <name> =` in a barrel-target file (keep modules single-responsibility); sub-file components resolve by one-hop import.

## webjsx and Component Behaviour Pitfalls

- `applyDiff` (vendor/webjsx/applyDiff.js:43) throws `Cannot read properties of undefined (reading 'key')` when children mix keyed VElements with primitive string siblings; wrap raw text in a keyed `<span>`.
- A `null` prop renders the string `"null"` (`id: x || null` -> `id="null"`, `href="null"` stays a tab-stopped link). Spread conditionally: `...(id ? { id } : {})`.
- A component returning a bare element on one branch must carry the caller's `key` on THAT element, else siblings collapse in the keyed diff. `Select` forwards `key` in the bare branch (the workspace kit's single-entry pickers can be restored; re-verify against two sibling Selects).
- A bare `null` among keyed siblings crashes applyDiff: build children with `.filter(Boolean)` (`lint-null-children`). A branching component (loading/empty/list) gives each branch a distinct `key` on one stable wrapper, else same-shaped branches patch in place and leave stale text. `SearchInput` must return the same wrapper shape every render (applyDiff cannot morph element types at a keyed slot).
- `ref` fires BEFORE children are appended: wire-up needing descendants (modal Tab trap, autofocus) defers a tick; refs re-fire every render (guard idempotency) and with `null` on unmount (run stored teardown). Never return a real DOM node from a one-shot helper as a diffable VElement.
- Focus-on-open uses `setTimeout(0)`, never `queueMicrotask` (the opening click's default focus runs after a same-tick microtask and steals it back; breaks Escape/Tab-trap).
- Interactive rows never nest buttons in `role=button`/`option`: plain container with a real open `<button>` and sibling action buttons; current channel `aria-current="page"`. A `Side` item with neither `href` nor `onClick` renders `<a>` with NO href; sidebar group labels are a `div`.
- `WorkspaceShell` resize ceilings (`WS_RESIZE_CLAMP`) sit above the CSS fluid `clamp()` ceilings (else drags are inert on wide viewports); inline `--ws-*-w` beats the collapsed class, so collapsing removes it.
- file-browser: row rails are owned by `data-file-type` (never hand-apply `.rail-*`); FileViewer needs `data-file-type` on head AND body; DropZone needs `preventDefault` on `document`; UploadProgress reads `data-pct`; BreadcrumbPath `onNav(i)` is segments-to-keep. Full set: rs-learn "file-browser primitives caveats".

## Probing Whether a Control Works

Verify BEHAVIOUR, never handler presence. `el.onclick` is always `false` (webjsx binds via `addEventListener`, `vendor/webjsx/attributes.js:15`); re-renders are async (`kit.schedule()` defers via `queueMicrotask`, `src/bootstrap.js`). Probe: click, `await` ~60-80ms, RE-QUERY the element (the node is replaced), compare. Exclude external `http(s)` links. Skipping this reported "20 of 20 controls inert" where the truth was 0 of 22.

## Kit and Specimen Specifics

- **Specimens (`preview/*`)** render REAL components, never hand-copied markup; overlays render open; no-op handlers are `inertSpecimenHandler`; placeholder anchors carry `data-specimen`. Fixed-colour swatches take `--ink`/`--paper` text, never `--panel-0`; captions use solid tier-3 colour, not opacity. `preview/motion-default.js` reuses SDK `[data-anim]` inside `prefers-reduced-motion: no-preference`; never animate.css (CDN SecurityError on `document.styleSheets`).
- **OS kit:** `wm.css` links BEFORE `theme.css` and is a raw sheet, so theme.css window rules carry `.ds-247420`; `!important` on window geometry and print is load-bearing (wm.css mobile band and `wm.js` inline drag styles only lose to it). The kit does not link `app-shell.css`, so theme.css styles the skip link.
- **Hand-authored kits:** blog/docs ship their own skip link and inline scripts (no AppShell/importmap).
- **signin** reads config from `globalThis.__DS_AUTH` (no Vite: `import.meta.env` is undefined and throws). slide_deck never sets slide `accent` (it feeds `--slide-accent` as text `color:`).
- **freddie pages:** runtime is `makePage`; failures route through `ctx.failLoad/failError/failNote`; destructive actions use ConfirmDialog (no backend undo). Chat page: persist the active sessionId for WS replay; clear `_live` per turn INSIDE the replay loop; never infer `busy` from a leftover `_live`; stale socket handlers bail. `/api/config` takes one `{key,value}` write at a time; `/api/models/availability/rebuild` returns 202, so poll and treat an elapsed ceiling as "unknown", not "failed". Re-verify other `/api/*` shapes against freddie.
